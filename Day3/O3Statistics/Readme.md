### Statistics
- Statistice provides the mathematical framework for 
- understanding data.
- making inference from samples.
- Evaluation of model uncertinity
- validating hypotheses

#### Python implementation for statistics
- numpy
- pandas
- scipy.stats

#### Key Capabilities
- Descriptive Analysis : Measure of central tendency, dispersion,shape(skewness,kurtosis) and statiscal moments.

- Probability & Distribution : Modeling real-world distribution(Normal,Binomial,Exponential, Poisson) and applying Bayes Theorem

- Inferential statistics : Parameter estimations, Confidence intervals, Central Limit Theorem(CLT) and Hypothesis Testing(t-tests,Chi-square, ANOVA)
